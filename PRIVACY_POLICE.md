# Privacy Policy

## 1. General Provisions

This document describes the data processing and storage policy of the **Math Solver**

The Application is a client-side web application designed to generate and manage mathematical quizzes.

The Application operates entirely in the user’s browser and does not require user registration.

---

## 2. Data Collection and Usage

### No Personal Data Collected

The Application does **not** collect, process, or store any personal data such as:

- Name
- Email address
- Phone number
- Geolocation
- IP address
- Payment information

No personal data is transmitted to external servers or third parties.

---

### Local Storage Usage

The Application uses the browser’s **localStorage** mechanism exclusively to improve user experience.

The following data may be stored locally:

- Quiz settings (difficulty level, configuration options)
- Test progress
- Timer state
- Quiz results and scores
- User Identifier

User Identifier is a randomly generated UUID is stored with uuid. It's generated locally only in the browser and does not carry any personal information.

This data is stored only in the user’s browser and is not accessible by the developer or any external entity.

---

## 3. Cookies

The Application uses a technical cookie solely to:

- Store user consent to this Privacy Policy
- Prevent the cookie consent banner from appearing repeatedly

No tracking, marketing, or analytics cookies are used.

The cookie does not collect personal information.

---

## 4. Data Security

All stored information remains within the user's browser environment.

The Application does not connect to external databases or servers for data storage.

Since no personal data is processed, the risk of data misuse is minimized.

---

## 5. User Rights (GDPR Compliance)

In accordance with the General Data Protection Regulation (GDPR):

- Users have the right to access their stored data.
- Users have the right to delete stored data at any time.
- Users have the right to withdraw cookie consent.

Users may delete all stored data by:

- Clearing their browser cache
- Deleting site data in browser settings
- Removing localStorage entries manually via developer tools

---

## 6. Third-Party Services

The Application may use open-source libraries (e.g., React, Redux Toolkit), but these libraries do not collect or transmit user data within this Application.

No analytics or advertising services are integrated.

---

## 7. Changes to This Policy

The developer reserves the right to update this Privacy Policy if application functionality changes.

Any updates will be reflected in this document.
